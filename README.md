# SINDICS

Assistente de voz do síndico, no estilo JARVIS, criado por **Elison Cardoso — Síndico Profissional** (Sindicância Ethics).

- Diga **"SINDICS"** para chamar; diga **"pode descansar"** para encerrar.
- Consulta a Convenção e o Regulamento Interno de cada condomínio, notícias do Brasil e indicadores do Banco Central (IPCA, IGP-M, INCC, Selic, CDI, salário mínimo).
- Voz e inteligência via ElevenLabs Agents.

Acesse: https://sindicosincero-cmd.github.io/sindics/

Use no Chrome (computador ou Android). Os documentos dos condomínios ficam apenas na base da ElevenLabs, não neste repositório.
